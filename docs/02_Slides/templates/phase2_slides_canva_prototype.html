💡 ที่มาและความสำคัญ (Problem & Solution)

ทำไมต้อง Disney Lorcana PlayLab Cloud?

การแก้ปัญหาอุปสรรคของเกมการ์ด TCG ดั้งเดิม ด้วยนวัตกรรมระบบคลาวด์ยุคใหม่

❌ อุปสรรคของผู้เล่นและระบบเดิม (Pain Points)
  • ราคาการ์ดจริงสูงมาก: การทดสอบเด็คแข่งขันต้องใช้ทุนสูง ขาดแพลตฟอร์มทดลองฟรี
  • Dedicated Server ต้นทุนสูง: VM ที่เปิดตลอด 24 ชม. เสียค่าใช้จ่ายคงที่ แม้ไม่มีคนเล่น
  • HTTP Polling หน่วงสูง: การส่งข้อมูลกระดานแบบเดิมล่าช้า ไม่ตอบโจทย์เกมการ์ดเทิร์นต่อเทิร์น
  • UI ขาดมิติทางกายภาพ: ซิมูเลเตอร์ทั่วไปเป็นภาพ 2D แบนราบ ขาดสัมผัสความรู้สึกเปิดซอง/เล่นการ์ดจริง
✨ นวัตกรรมโซลูชันของเรา (PlayLab Cloud Solution)
  • เข้าถึงได้ทันทีผ่าน Web: ทดลองจัดเด็คและซ้อมเล่นได้ฟรี ไม่ต้องซื้อการ์ดจริง ไม่ต้องลงโปรแกรม
  • Serverless & Scale-to-Zero: จ่ายตามการใช้งานจริง ต้นทุนโครงสร้างพื้นฐาน $0.00 (Free Tier)
  • WebSockets Sub-50ms: ซิงค์พิกัดการลากวางการ์ดและการหมุนการ์ดเรียลไทม์ระหว่าง 2 ผู้เล่น
  • Luxury Physical TCG UI: แอนิเมชัน 3D Tilt Card Inspector, Booster Pack Opening, ฟิสิกส์สมจริง
Target Audience: ผู้เล่น TCG สายแข่งขัน, นักสะสมการ์ด, และผู้เล่นใหม่ Goal: Zero Cost ($0.00) • Sub-50ms Latency • Ultra-Fidelity TCG Simulation
🏗️ สถาปัตยกรรมคลาวด์ (Cloud Architecture Evolution)

Dual-Ready Cloud Model: Serverless & Multi-AZ IaaS

การออกแบบ 2 ระดับเพื่อรองรับทั้งความยืดหยุ่นระดับ Production และตอบโจทย์เกณฑ์คะแนนวิชา Cloud

⚡ สถาปัตยกรรมที่ 1: 100% AWS Serverless

เน้นความเบา ทนทาน และต้นทุน $0.00 Free Tier เหมาะสำหรับ Event-Driven Microservices:

• Compute: AWS Lambda (Auth Login/Register, Deck Manager, Room Router)
• API Gateway: HTTP API สำหรับ REST + WebSocket API สำหรับห้องเล่น
• Storage & DB: Amazon DynamoDB (Users, Decks, RoomStateTable)
• Async Queue: Amazon SQS สำหรับ Deck Synergy Analyzer
Pure Serverless Model
🚀 สถาปัตยกรรมที่ 2: Lean Multi-AZ IaaS (ASG)

ยกระดับเพื่อสาธิตทักษะ Cloud Infrastructure ตามเกณฑ์การให้คะแนนวิชา:

• Network: Custom Lean VPC (10.0.0.0/16) ข้าม 2 AZs (us-east-1a, us-east-1b)
• Traffic Dist: Application Load Balancer (ALB) + Health Check (/health)
• Compute Elasticity: EC2 Auto Scaling Group (Min 1, Max 3, CPU > 60%)
• Container: Docker Nginx (Port 80) + Node.js 20 Express & WebSocket (Port 3001)
IaaS Stage 2 Hardened
Security: Chained Security Groups (ALB -> EC2) • IAM LabRole via IMDSv2 Cost Guardrail: Zero NAT Gateway ($0.00) + 1-Click Scale-to-Zero
⚡ ระบบซิงค์ข้อมูลเรียลไทม์ (Real-time Multiplayer Engine)

Sub-50ms WebSocket Synchronization

การรับส่งพิกัดการลากวางการ์ด สถานะเทิร์น และระบบกู้คืนการเชื่อมต่ออัจฉริยะ

🔄 Optimistic UI Updates

เมื่อผู้เล่นลากการ์ดหรือหมุนสถานะ Ready/Exert การแสดงผลหน้าจอจะเปลี่ยนทันทีแบบไร้อาการกระตุก (0ms Local UI) ก่อนส่ง Event เข้าสู่ระบบ

Zero Latency Feeling
📡 Sub-50ms AWS Relay

WebSocket Server ทำการ Broadcast ข้อมูล (Card Moved, Exerted, Ink Added, Lore Changed) ไปยังคู่ต่อสู้ในห้องเดียวกันด้วยความหน่วง < 50ms

Live Tested on us-east-1
🛡️ Rejoin & Grace Period

ระบบรองรับกรณีผู้เล่นเน็ตหลุดชั่วคราวด้วย 60-Second Rejoin Window พร้อมเก็บ State ห้องไว้ใน DynamoDB พร้อม TTL ป้องกันข้อมูลตกค้าง

Auto Disconnect Recovery
Payload Events: JOIN_ROOM, CARD_MOVED, CARD_EXERTED, INK_CARD, QUEST_LORE, LEAVE_ROOM Consistency: Eventual Consistency with DynamoDB TTL
