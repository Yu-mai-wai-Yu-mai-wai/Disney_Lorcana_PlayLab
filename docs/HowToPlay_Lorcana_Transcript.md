# 🎮 วิธีการเล่น Disney Lorcana — ฉบับถอด Transcript

> ถอดจากวิดีโอสอนเล่นภาษาไทย (YouTube) — เนื้อหาครบทุกประเด็น ใช้เป็นคู่มือ + อ้างอิงการ์ดจริงในเกม

## 1. ภาพรวมเกม
- ผู้เล่นรับบทเป็น **Illumineer** ใช้น้ำหมึกเวทมนตร์ (Ink) เรียกตัวละครดิสนีย์ออกมาจากการ์ด
- เป้าหมาย: สร้างเรื่องราว (Lore) ผ่านการทำภารกิจ (Quest) ของตัวละคร

## 2. การ์ด 4 ประเภท

| ประเภท | หน้าที่ | หลังใช้ |
|---|---|---|
| **Character (ตัวละคร)** | ทำภารกิจ (Quest), ต่อสู้ (Challenge), ร้องเพลง (Sing) | อยู่สนาม |
| **Action (แอคชัน)** | เอฟเฟกต์ทันที (ใช้เวทมนตร์) | ทิ้งกองทิ้ง |
| **Item (ไอเทม)** | สนับสนุน ใช้ซ้ำได้หรือใช้แล้วหมด | อยู่สนาม |
| **Location (สถานที่)** | วางตัวละครเข้าไป + ได้คะแนนทุกเทิร์น | อยู่สนาม |

### ค่าพลังสำคัญของตัวละคร (3 ค่า)
- ⚔️ **พลังโจมตี** (วงกลม) — ใช้ตอน Challenge
- 🛡️ **พลังใจ/HP** (โล่) — ความเสียหายครบ = ถูกทำลาย
- ⭐ **Lore** (รอน) — ได้คะแนนเมื่อทำ Quest

### การ์ดเพลง (Song)
- การ์ด Action ประเภทเพลง (มีสัญลักษณ์เพลง) — **ไม่ต้องจ่ายค่าร่าย** แต่ให้ตัวละคร "ร้องเพลง" แทน (Exert ตัวละคร)

## 3. เงื่อนไขชนะ
1. **ได้ 20 Lore** ก่อน → ชนะ
2. ฝ่ายตรงข้าม**จั่วการ์ดตอนเริ่มเทิร์นไม่ได้** (กองหมด) → เราชนะ

## 4. กฎการจัดเด็ค
- **ขั้นต่ำ 60 ใบ** (มากกว่าได้ ไม่จำกัด)
- การ์ดซ้ำได้ **ไม่เกิน 4 ใบ/การ์ด**
- ใช้หมึกได้ **ไม่เกิน 2 สี** ใน 1 เด็ค
- มี 6 สี: Ruby (แดง), Sapphire (น้ำเงิน), Emerald (เขียว), Amethyst (ม่วง), Steel (เทา), Amber (เหลือง)

## 5. การเริ่มเกม
1. กำหนดผู้เริ่มก่อน (โยนเหรียญ/ทอยเต๋า)
2. ทั้งคู่จั่ว **7 ใบ**
3. **Mulligan**: การ์ดไม่ชอบ → วางใต้เด็ค → จั่วคืนตามจำนวน → สับเด็ค
4. ผู้เล่นคนแรก **ไม่จั่วการ์ดในเทิร์นแรก**

## 6. ขั้นตอนเทิร์น (Ready → Set → Draw)
1. **Ready** — การ์ดที่นอน (Exerted) → หันตั้ง (พร้อมใช้)
2. **Set** — ตัวละครที่เพิ่งลงเทิร์นก่อน (หมึกยังไม่แห้ง) → พร้อมเล่น
3. **Draw** — จั่ว 1 ใบ
4. **ลง Ink 1 ใบ** — การ์ดที่มีสัญลักษณ์หมึก (วงกลมมุมซ้ายบน) → โชว์ฝ่ายตรงข้าม → คว่ำลง Inkwell (ทำได้เทิร์นละ 1)
5. **ร่ายการ์ด** — จ่ายค่าร่าย (Exert หมึกตามจำนวน) → เรียกตัวละคร/ไอเทม/แอคชัน
6. **Quest / Challenge / ใช้เอฟเฟกต์**
7. **Pass Turn**

### ⚠️ กฎ "หมึกยังไม่แห้ง" (Ink Dry)
- ตัวละครที่ลงในเทิร์นนี้ → **ยังทำอะไรไม่ได้** (Quest/Challenge ไม่ได้)
- เทิร์นถัดไป → พร้อมใช้

## 7. Quest (ทำภารกิจ) — การได้คะแนน
- ตัวละครที่พร้อม (หมึกแห้ง) → **Exert (นอน)** → ได้ Lore ตามค่าการ์ด
- เช่น ตัวละครมี ⭐1 → ได้ 1 คะแนน

## 8. Challenge (ต่อสู้)
- โจมตีได้เฉพาะตัวละครที่ **นอน (Exerted)** อยู่ฝั่งตรงข้าม
- ตัวละคร 2 ตัว **แลกดาเมจกัน** (ทั้งโจมตีและรับโดน)
- ความเสียหายรวม **เท่ากับพลังใจ** → ตัวละครถูกทำลาย (Banish) ไปกองทิ้ง
- ผู้โจมตีโดนตอบโต้ด้วย → ตัวเองก็ได้ความเสียหาย
- หลังโจมตี → ตัวโจมตี Exert (นอน)

## 9. จุดเด่นของหมึกทั้ง 6 สี

| สี | จุดเด่น |
|---|---|
| 🔴 **Ruby (แดง)** | บุกโจมตี พลังโจมตีสูง, Rush (โจมตีได้ทันที), ทำลายตัวละคร |
| 🔵 **Sapphire (น้ำเงิน)** | เร่ง Ink (Ramp), ร่ายการ์ดแพงง่าย, บริหารทรัพยากร |
| 🟢 **Emerald (เขียว)** | ก่อกวน: บังคับทิ้งการ์ด, ลด Lore ฝ่ายตรงข้าม, สมดุล |
| 🟣 **Amethyst (ม่วง)** | จั่วการ์ด, บังคับให้ฝ่ายตรงข้ามนอนค้าง (ไม่ Ready), จอมเวท |
| ⚪ **Steel (เทา)** | ทนทาน HP สูง, Resist (ลดดาเมจ), ป้องกันเพื่อน |
| 🟡 **Amber (เหลือง)** | ฮีล, สนับสนุนทีม, เพิ่ม/ลดพลังโจมตี, Teamwork |

## 10. สรุป Flow การเล่น
```
เริ่มเกม → จั่ว 7 → Mulligan → 
┌─ เทิร์นเรา: Ready → Set → Draw → ลง Ink 1 → ร่ายการ์ด → Quest/Challenge → Pass ─┐
└────────────── ฝ่ายตรงข้ามทำเหมือนกัน (สลับกัน) ────────────────────────────────────┘
จนใครได้ 20 Lore ก่อน → ชนะ!
```

## 🎯 เทียบกับเกมของเรา (Lorcana PlayLab)
- ระบบในเกมรองรับครบ: Inkwell (Exert หมึก), Quest (Exert ตัวละคร + Lore), Challenge (แลกดาเมจ + Banish), Song (ร้องเพลงแทนค่าร่าย), Ready/Set/Draw อัตโนมัติตอน Start Turn
